Muskelaufbau-Tracker – Installation

1. Alle Dateien dieses ZIP-Archivs in das Hauptverzeichnis eines GitHub-Pages-Repositories hochladen.
2. In GitHub unter Settings > Pages die Veröffentlichung aus dem main-Branch und dem Root-Verzeichnis aktivieren.
3. Die angezeigte HTTPS-Adresse im Samsung Internet Browser öffnen.
4. Im Browsermenü 'Seite hinzufügen zu' / 'Startbildschirm' wählen (Bezeichnung kann abweichen).
5. Einen Probesatz speichern, Browser schließen, erneut öffnen und Historie kontrollieren.

Die Trainingshistorie liegt lokal im Browser (localStorage), nicht auf GitHub. Regelmäßig JSON-Backup exportieren. Daten sind nicht zwischen Geräten synchronisiert.

Achtung: Der veröffentlichte Programmcode ist bei GitHub Pages öffentlich zugänglich. Persönliche Trainingsdaten werden nicht in das Repository hochgeladen.
